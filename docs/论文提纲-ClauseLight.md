## 二、建议摘要逻辑

针对 PDF、图片等非结构化合同难以快速审查的问题，设计并实现一个基于大语言模型的合同风险辅助审查系统。系统采用文档解析、条款结构化、多维度并行风险分析、冲突复核和结果聚合的多阶段 Agent 架构，并结合本地规则库与受控法规资料，为合同条款生成风险等级、问题说明、法律依据和修改建议。通过功能测试、脱敏案例和可复现实验工程验证系统流程与可观测性；在没有专家标注时不评价法律判断准确性。最后分析系统在 OCR 质量、模型输出稳定性、知识库检索和法律专业复核方面的局限。

摘要中的“提高准确率”“显著优于”“有效降低”等结果性表述，必须等实验数据产生后再使用。

## 三、正文结构

### 1 引言

#### 1.1 研究背景

- 合同内容通常以 PDF、扫描图片或复杂文档形式存在；
- 普通用户难以快速定位付款、违约、责任、知识产权和争议解决等风险；
- 大语言模型具备文本理解能力，但单次分析存在遗漏、输出不稳定和缺乏结构化依据等问题。

#### 1.2 研究内容

本文主要解决以下工程问题：

以文档入口、结构解析、五维 Worker、冲突复核、结果聚合和本地化存储为主要工程工作，重点说明模块之间的输入输出和异常处理。

#### 1.3 论文组织结构

说明第 1 章至第 7 章的内容，并指出本文以系统设计、工程实现和功能验证为主，不把有限案例解释为准确率实验。

### 2 相关技术与需求分析

#### 2.1 相关技术与研究基础

介绍结构化输出、Prompt Chaining、Parallelization 和工具调用，不展开泛泛的模型发展史。

#### 2.2 功能需求

- 文件上传与格式识别；
- OCR 与文本层解析；
- 条款识别和合同类型判断；
- 权责、财务、知识产权、争议解决和通用风险分析；
- 风险等级、依据和修改建议展示；
- 失败重试、人工复核和本地数据存储。

#### 2.3 非功能需求与设计目标

- 本地优先；
- 模块可替换；
- 输出结构化；
- 支持远程模型和本地模型，默认本地优先；远程处理必须显式授权；
- 不把系统定位为法律意见提供者。

### 3 系统总体设计

#### 3.1 系统总体架构

对应证据：`docs/AGENT_ARCHITECTURE.md`、`README.md`。

建议插图：系统总体架构图。

数据流：

```text
合同文件 → 文档解析 → 条款结构化 → 知识检索
        → 五维并行风险分析 → 冲突检测与复核
        → 综合评分与建议 → 前端结果展示
```

#### 3.2 多阶段 Agent 流程

- Stage 1：合同类型识别与条款拆分；
- Stage 2：五个风险 Worker 并行分析；
- Stage 3：风险聚合、冲突标记和结果总结；
- 可选：记忆、Wiki、Skill 上下文和分析后知识提炼。

#### 3.3 核心数据对象

- 文档入口模块：`server/core/document_ingress.py`；
- Agent 编排模块：`server/core/agent.py`；
- 条款解析模块：`server/core/workers/parser.py`；
- 风险 Worker：`server/core/workers/workers.py`；
- 结果评估模块：`server/core/workers/evaluator.py`；
- 知识库模块：`server/core/knowledge.py`；
- LLM 统一网关：`server/core/llm.py`。

#### 3.4 数据库与接口设计

介绍合同、分析结果、条款分析、知识规则和法规资料等主要数据对象，以及合同分析 API 的调用流程。

### 4 关键模块设计与实现

- 文字型 PDF、图片和其他文档的入口选择；

- 文本不足、OCR 失败和低置信度时的处理；
- 解析结果统一为全文、页面和结构信息。

#### 4.3 五维并行风险分析

#### 4.4 冲突检测与人工复核

### 6 讨论

#### 6.1 系统特点

- 将开放式合同分析拆成可观察阶段；
- 通过维度分工减少单次分析的任务混杂；
- 支持结构化输出和人工复核；
- 本地存储降低合同数据外传风险。

#### 6.2 系统局限

- 模型结果仍受提示词、模型版本和温度影响；
- 法律依据和行业惯例需要专业人员复核；
- 当前知识库学习链路仍需进一步验证；
- 合同类型和样本覆盖有限；
- 系统不构成法律意见。

#### 6.3 后续工作

- 建立更规范的脱敏合同数据集；
- 引入法律背景标注者；
- 固定风险规则和评分公式；
- 改进冲突复核策略；
- 评估不同模型和本地模型的差异。
