## 三、当前不能直接写成论文结论的内容

- 不能写“准确率达到某个百分比”：没有人工金标准；
- 不能写“系统显著优于普通 LLM”：没有对照实验；
- 不能写“支持 44 份合同数据集”：上传目录高度重复且包含无效文件；
- 不能写“系统稳定运行”：日志中曾出现大量知识库接口 500 错误；
- 不能写“知识库自动学习有效”：数据库有自动学习记录，但没有正确率或人工确认实验；
- 不能写“法律判断准确”：没有法律专业人员标注和复核；
- 不宜把测试通过数直接表述为合同风险识别准确率；当前全量测试无失败，但有 2 个可选依赖测试跳过和 8 个警告，需要在投稿前逐项归类。[TEST-BASELINE-001]

## 四、已确认的技术问题

### 1. Prompt 测试引用缺失模块（已处理）

`tests/test_prompts.py` 引用了以下模块，但当前 `server/core/prompts/` 目录中未找到对应文件：

- `server.core.prompts.analyze`；
- `server.core.prompts.classify`；
- `server.core.prompts.score`；
- `server.core.prompts.split`；
- `server.core.prompts.suggest`。

该问题源于测试仍引用已被当前架构移除的旧 Prompt 模块。现已将测试同步到当前 Worker 和 Distill Prompt 构造函数，全量 pytest 可以正常收集并执行。

### 2. `/api/devices` 历史失败（已处理）

历史失败用例 `tests/test_main.py::TestDevicesEndpoint::test_list_devices` 请求了旧路径 `/api/devices`，而当前路由为 `/api/connection/devices`。现已同步测试路径并按当前返回结构校验，全量测试不再因该问题失败。

### 3. 历史数据库迁移不一致

旧运行日志中出现 `knowledge_rules.status` 字段不存在导致的数据库错误，并伴随大量知识库相关 500 响应。当前数据库表结构已包含 `status` 字段，但历史日志仍然反映过迁移不一致问题。论文中应把它作为开发过程中的问题或局限，不应把历史运行直接概括为稳定运行。

### 4. 外部模型和 Embedding 兼容问题

运行日志记录过：

- 外部模型不支持当前 `response_format` 类型，Outlines 结构化输出失败后回退 JSON 解析；
- Embedding 初始化曾因 `SentenceTransformer` 参数兼容问题失败；
- 部分流程因此依赖降级路径。

这些内容可写入“异常处理和系统局限”，不能被隐去。

### 1. 与 ClauseLight 直接相关的要求

官方组稿方向明确包含“智能技术”和“系统实现”。其中“智能技术”包括人工智能、自然语言处理及行业应用；“系统实现”包括系统架构、技术实现过程、性能优化和工程实践案例。因此 ClauseLight 适合按“系统实现”方向投稿，文章重点应放在系统架构、处理流程、模块实现和案例验证，不把论文包装成大模型算法论文。

官方投稿须知要求文章观点明确、语言简练、论据正确；稿件应为作者本人研究成果，保证著作权，不得抄袭、剽窃或侵权；须提供中英文题目、作者及单位、中英文摘要及关键词，并附参考文献；图表需要清晰、有连续图表序号和图表题，并在正文中作相应描述。

### 2. 官方引言要求对本文的影响

官方引言说明要求引言交代背景、目的、相关工作、存在问题和本文工作，但要开门见山、避免教科书式常识和大篇幅历史叙述；不能使用“填补空白”“首次发现”等夸大表述；引言不应与摘要重复，最好不插图、列表或公式推导。

因此，Markdown 初稿中的引言需要压缩为连续的 3—4 个自然段，删除列表化的“研究内容”堆叠；具体模块和测试证据移到第 2—5 章。

### 3. 官方图表要求对本文的影响

官方表格规范要求使用三线表，表号和表题置于表格上方，并提供对应英文表题；图题置于图下方，全文按出现顺序连续编号；图表应随文编排，并在首次提及后出现。

官方插图规范建议流程图采用简单框架图，尽量不使用底色、灰度、阴影和三维效果；录用后优先提供可编辑的矢量图，印刷目前以黑白为主。ClauseLight 的系统架构图应按黑白线框绘制，风险等级不能只靠颜色区分，应同时标注“红色/黄色/绿色”文字。

### 4. 从当期文章可观察到的版式要素

官网 2026 年第 42 卷第 16 期的文章页面同时展示中文题目、英文题目、作者、作者单位、作者简介、中图分类号、基金项目字段、中文摘要、英文摘要和中英文关键词。该期既有教学研究文章，也有“系统设计”类文章，常见篇幅为 3—5 个页码。本文应准备这些字段，但作者姓名、单位、作者简介、中图分类号和通讯作者信息不能凭空填写，需由作者提供或在投稿系统中确认。
