# ClauseLight 手机端 PWA 设计提示词

## 任务

为合同红绿灯手机端 PWA 编写完整的设计原型。原型使用 React+Babel 构建，仅供视觉和交互参考。
实际实现时需转换为纯 HTML + CSS + JavaScript（ES6+），不引入任何框架。

## 设计方向

**移动端优先的工具型应用**，风格与桌面端保持一致（V1 Notion 风格）。
- 干净、高效、信息密度适中
- 红黄绿三色作为风险等级核心视觉语言
- 底部 Tab 导航，最多 4 个入口
- 大触控区域，手指友好
- 支持亮色/暗色主题（默认跟随系统，可手动切换）

## 技术约束

- 原型文件使用 React + Babel（仅用于设计参考）
- 实际实现必须纯 HTML + CSS + JS，无框架
- 无外部 CDN 依赖（PWA 离线可用）
- 所有文本使用中文
- 字体使用系统字体栈
- 所有交互状态需在原型中体现

## 页面设计规格

### 0. 全局布局

**底部 Tab 导航栏**：
- 固定在屏幕底部，高度 56px + safe-area-inset-bottom
- 4 个 Tab：首页 | 历史 | 知识库 | 设置
- 选中态：accent 色图标 + 文字，未选中：text-tertiary
- 图标在上，文字在下，间距 2px
- 毛玻璃背景效果：`backdrop-filter: blur(20px); background: rgba(255,255,255,0.85)`
- 暗色主题下背景：`rgba(25,25,25,0.9)`

**页面容器**：
- 除底部导航外全屏滚动
- 内容区 padding-bottom: 72px（为底部导航留空间）
- 页面切换无动画（瞬切），避免性能问题

**状态栏适配**：
- `viewport-fit=cover` + `safe-area-inset-*` 适配刘海屏
- 顶部内容不被状态栏遮挡

这是用户打开 App 后看到的第一个页面，核心目标：**让用户最快路径开始分析合同**。

**布局（从上到下）**：

```

│                             │
│    ┌───────────────────┐    │
│    │                   │    │
│    │   📷 拍照上传      │    │  ← 主操作区：大圆角卡片
│    │   选择文件上传     │    │     两个并排按钮，各占 1/2 宽度
│    │                   │    │
│    └───────────────────┘    │
│                             │
│  ┌── 连接状态条 ──────────┐  │  ← 连接状态指示器
│  │ 🟢 已连接到电脑端      │  │
│  └───────────────────────┘  │
│                             │
│  最近分析                    │  ← 分区标题
│  ┌───────────────────────┐  │
│  │ 🏠 房屋租赁合同        │  │  ← 最近分析卡片
│  │    评分 35  高风险     │  │
│  │    2026-06-12         │  │
│  ├───────────────────────┤  │
│  │ 💼 劳动合同           │  │
│  │    评分 72  低风险     │  │
│  │    2026-06-10         │  │
│  └───────────────────────┘  │
│                             │
├─────────────────────────────┤
│  🏠首页  📋历史  📚知识  ⚙️设置 │  ← 底部 Tab 导航
└─────────────────────────────┘
```

**主操作区**：
- 两个并排大按钮，高度 120px，圆角 16px
- 「拍照上传」按钮：绿色渐变背景（`linear-gradient(135deg, #38a169, #2383e2)`），白色相机图标 + 文字
- 「选择文件」按钮：浅灰色背景（`bg-muted`），灰色文件夹图标 + 文字
- 按钮点击后有缩放反馈（`transform: scale(0.97)`，150ms）
- 拍照按钮调用 `<input type="file" accept="image/*" capture="environment">`
- 选择文件按钮调用 `<input type="file" accept="image/*,.pdf">`

**连接状态条**：
- 全宽圆角条，高度 40px
- 三种状态：
  - 🟢 已连接到电脑端（绿色圆点 + 文字）
  - 🟡 使用云端 API（黄色圆点 + 文字）
  - 🔴 离线模式（红色圆点 + 文字）
- 点击可进入设置页修改连接方式
- 背景色跟随状态：绿色 `risk-green-bg`、黄色 `risk-yellow-bg`、红色 `risk-red-bg`

**最近分析列表**：
- 最多显示 5 条
- 每条：左侧风险色条（3px 宽，圆角）+ 标题 + 评分 + 风险等级文字 + 日期
- 点击跳转到结果详情页
- 空状态：居中显示「还没有分析过合同，拍一张试试」+ 空文件夹图标

用户上传合同后进入此页面，展示分析进度和实时结果。

```
│  │                        │ │
│  │  ● ── ● ── ◉ ── ○ ── ○ │ │  ← 步骤进度条
│  │  OCR  拆解  分析  建议  评分│ │
│  │                        │ │
│  │  ████████░░░░  60%     │ │  ← 总体进度条
│  │                        │ │
│  └────────────────────────┘ │
│                             │
│  ┌── 实时结果区 ──────────┐ │
│  │                        │ │
│  │  第三条 租金及支付方式   │ │  ← 逐条出现的分析结果
│  │  🔴 高风险             │ │     每完成一条，卡片滑入
│  │  逾期支付滞纳金过高     │ │
│  │                        │ │
│  │  第四条 押金           │ │
│  │  🟡 中风险             │ │
│  │  押金退还条件模糊       │ │
│  │                        │ │
│  └────────────────────────┘ │
│                             │
├─────────────────────────────┤
│  🏠首页  📋历史  📚知识  ⚙️设置 │
└─────────────────────────────┘
```

**进度区**：
- 步骤进度条：5 个圆点（●）+ 连线（──），当前步骤高亮放大，已完成步骤填充 accent 色，未开始灰色
- 步骤名称：OCR → 条款拆解 → 风险分析 → 修改建议 → 综合评分
- 当前步骤文字：大号字体 + 旋转 spinner 动画
- 总体进度条：高度 6px，圆角，accent 色填充，百分比文字

**实时结果区**：
- 每完成一条分析，卡片从底部滑入（`transform: translateY(20px) → 0`，300ms ease-out）
- 卡片样式：左侧 3px 风险色条 + 圆角 + 浅色背景
- 卡片内容：条款编号 + 标题 + 风险徽章 + 一句话摘要
- 卡片之间间距 8px

**错误状态**：
- 分析失败时显示红色错误卡片 + 重试按钮
- 部分失败时显示已完成的结果 + 失败提示

**用户操作**：
- 返回按钮：弹出确认对话框「分析正在进行中，确定要离开吗？」
- 分析完成后自动跳转到结果页（3 秒倒计时，可点击立即跳转）

**总览卡片**：
- 圆角 16px，内边距 24px
- 评分数字：48px 粗体，颜色根据分数变化（≥70 绿色，50-69 黄色，<50 红色）
- 风险分布：三个彩色圆点 + 数字，下方是分布条（高度 8px，三色分段）
- 一句话建议：带图标的文字行，颜色跟随建议类型

**条款筛选 Tab**：
- 水平滚动的 Tab 栏，每个 Tab 显示名称 + 数量
- 选中态：底部 2px accent 色指示条
- 点击筛选下方条款列表

**条款卡片**：
- 左侧 4px 风险色条
- 顶部：条款编号（粗体）+ 风险徽章（圆角 pill）
- 问题摘要：直接显示，不需要展开
- 通俗解释：带 💡 图标的区块，浅色背景
- 修改建议：可折叠，默认收起，点击展开显示蓝色背景区块
- 法律依据：可折叠，默认收起，点击展开显示斜体灰色文字
- 反馈按钮：两个并排按钮，「👍 准确」和「👎 不准确」，点击后按钮状态变为已选中
- 卡片间距 12px

**底部操作栏**：
- 固定在内容区底部（不在 Tab 导航上方）
- 两个按钮并排：「分享报告」（accent 色）+「重新分析」（灰色边框）
- 分享调用 Web Share API（navigator.share），降级为复制链接
- 重新分析跳转回首页

**空状态**：
- 分析结果为空时显示：「分析完成，但没有识别到有效条款」+ 返回首页按钮

## 交互规格

### 页面切换
- Tab 切换：瞬切，无过渡动画
- 进入详情页：从右侧滑入（`translateX(100%) → 0`，250ms ease-out）
- 返回详情页：向右侧滑出（`0 → translateX(100%)`，250ms ease-in）

### 按钮反馈
- 所有可点击元素：`active` 时 `transform: scale(0.97)`，100ms
- 主要按钮：点击后显示 loading spinner，禁用重复点击

### 下拉刷新
- 首页和历史页支持下拉刷新
- 顶部显示 spinner + 「下拉刷新」文字
- 松手后触发数据重新加载

### 空状态
- 每个列表页都有空状态设计
- 空状态包含：大图标 + 描述文字 + 行动按钮（可选）

### 错误处理
- 网络错误：Toast 提示「网络连接失败，请检查设置」
- 分析失败：页面内显示错误卡片 + 重试按钮
- 数据加载失败：显示「加载失败，点击重试」
